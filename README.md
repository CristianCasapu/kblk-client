# KBLK Client — release-uri

Release-urile modului **KBLK Client** (Fabric, Minecraft Java 1.21.11) pentru serverul [KBLK MC](https://kblk.space)
(`mc.kblk.space:35565`).

- Descărcare și instrucțiuni de instalare: **https://kblk.space/#client**
- Clientul se actualizează singur: citește `https://kblk.space/client/version.json`, iar dacă manifestul nu răspunde,
  ultimul release din acest repo.
- Fiecare release are un singur jar, `kblkclient-X.Y.Z.jar`, cu tag `vX.Y.Z`. Suma SHA-256 e trecută în descrierea release-ului
  și în `version.json`.

Probleme sau întrebări: contact@kblk.space
